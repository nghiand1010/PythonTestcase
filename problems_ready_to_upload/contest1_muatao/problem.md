# Unknown

**URL:** https://oj.tica.edu.vn/problem/contest1_muatao

---

Lúc bạn capybara Susu đang đi về nhà, Susu đi qua một siêu thị, và tự nhiên thèm ăn quả táo. Susu muốn mua ~N~ quả táo. Susu phải trả ~K~ đồng cho quả táo thứ 1, ~K * 2~ đồng cho quả thứ 2, ~K * 3~ đồng cho quả thứ 3, và cữ như vậy. 

Tại vì Susu có rất nhiều tiến, Susu có thể mua bao nhiêu quả táo cũng được. Nhưng Susu không giỏi toán, nên không biết cần phải trả bao nhiêu tiền.

Bạn hãy giúp Susu tính bạn ấy cần phải trả bao nhiêu đồng.

----------

**Input:**
----------

Nhập vào hai số nguyên dương N và K (~1 ≤ N, K ≤ 100~)
 
**Output:** 
----------

In ra số đồng Susu cần phải trả

**Ví dụ 1:**
----------

Input:
----------



```
10
3
```


Output:
----------



```
165
```


**Ví dụ 2:**
----------

Input:
----------



```
43
17
```


Output:
----------



```
16082
```
