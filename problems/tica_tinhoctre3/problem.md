# Unknown

**URL:** https://oj.tica.edu.vn/problem/tica_tinhoctre3

---

Chuỗi S là HOITHITINHOCTRE

Cho 1 xâu A là viết chuỗi S liên tục đến vô tận
Người ta sắp xếp xâu A thành một tam giác xâu như sau:



```
H
O   I
T   H    I
T   I    N    H  
O   C    T    R    E   
H   O    I    T    H    I    
T   I    N    H    O    C    T
R   E    H    O    I    T    H    I
```


Hình gồm 3 vòng màu vàng, xanh, cam liên tiếp  
* Vòng 1 màu vàng (Yellow) : Ký tự H, O, T, T, O, H, T, R, E, H, O , I, T, H, I, T, I, E, H, I, I
* Vòng 2 màu xanh (Green) . Ký tự: H, I, C, O, I, N, H, O, C, H, R, N
* Vòng 3 màu cam (Orange) . Ký tự  T, I, T


Input: 

```
Nhập vào 1 số nguyên dương N
```


Output:


```
1. Dòng 1: Ký tự thứ N trong xâu A
2. Dòng 2: In ra màu của Ký tự thứ N
```

### Ví dụ:

### Input:


```
8
```

### Output:


```
I
Green
```
