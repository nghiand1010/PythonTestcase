# Unknown

**URL:** https://oj.tica.edu.vn/problem/mangtoida

---

Thầy của bạn Mít cho bạn ấy một mảng ~a~ có ~N~ phần tử: ~a_1, a_2, a_3, ..., a_n~. Mít có thể thay một phần tử ~a_i~ thành ~-a_i~. Thầy bảo bạn ấy thay ~K~ phần tử như thế và tính tổng của mảng. Nếu Mít tính được tổng tối đa thỉ thầy sẽ cho bạn ấy ~1000~ robux.

Hãy giúp bạn Mít tính tổng tối đa của mảng ~a~

----------

**Input:**
----------

Dòng đầu tiên chứa một số nguyên dương ~N~ (~1 ≤ N ≤ 100~)

Dòng thứ hai chứa một số nguyên dương ~K~ (~1 ≤ K ≤ N~)

Dòng thứ ba chứa ~N~ số nguyên ~a_1, a_2, a_3, ..., a_N~ (~-200 ≤ a_i ≤ 200~)
 
**Output:** 
----------

In ra một số nguyên dương: Tổng tối đa của mảng ~a~

**Ví dụ 1:**
----------

Input:
----------



```
3
1
4 2 3
```


Output:
----------



```
5
```


**Ví dụ 2:**
----------

Input:
----------



```
5
3
-2 -5 6 1 -9
```


Output:
----------



```
23
```
