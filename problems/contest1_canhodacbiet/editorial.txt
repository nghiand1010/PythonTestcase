Cách 1:
```
x = int(input())
ans = 0

for i in range(1, x % 10):
    for j in range(1, 5):
        ans += i * j
for i in range(1, len(str(x)) + 1):
    ans += i * (x % 10)
print(ans)
```

x = int(input())
a = x % 10 - 1
s = len(str(x))
n = (1 + a) * a // 2 * 10
m = (1 + s) * s // 2 * (a + 1)
print(n + m)
