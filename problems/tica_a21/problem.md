# Unknown

**URL:** https://oj.tica.edu.vn/problem/tica_a21

---

Cho một số nguyên dương K. Yêu cầu: Hãy tìm N nhỏ nhất sao cho (N!) có ít nhất K chữ số 0 tận cùng

Input:




```
Gồm một dòng duy nhất chứa số nguyên dương K (1<nK≤10^15 ).

```
Output: In ra kết quả bài toán.

Ví dụ:

##B10.INP       



```
3
```

##B10.OUT


```
15
```
