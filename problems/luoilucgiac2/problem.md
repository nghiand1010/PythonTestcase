# Unknown

**URL:** https://oj.tica.edu.vn/problem/luoilucgiac2

---

Một lưới lục giác có tầng K bao gồm một vùng trung tâm và các vòng bao quanh nó. Ví dụ như hình sau là lưới lục giác bậc 3 với đầy đủ các hình và cạnh.

![](/martor/dfb8549f-9937-42de-95b2-fb2a964b75cf.png)

### Ví dụ:
- Nếu sử dụng ít hơn 6 đoạn thẳng thì sẽ không vẽ được hình lục giác nào.
- Nếu sử dụng ít nhất 6 đoạn thẳng thì sẽ vẽ được lưới lục giác hoàn chỉnh bậc 0.
- Nếu sử dụng ít nhất 30 đoạn thẳng thì sẽ vẽ được lưới lục giác hoàn chỉnh bậc 1. ...

### Yêu cầu
Cho một số nguyên dương N là số đoạn thẳng được sử dụng để vẽ một lưới lục giác đồng tâm. Hỏi với số đoạn thẳng đó thì sẽ vẽ được lưới lục giác hoàn chỉnh bậc mấy là tối đa?

### Input
- Dòng đầu tiên chứa số nguyên dương N (1 ≤ N ≤ 10^18)

### Ví dụ 1:

### Input:


```
5
```


### Output:


```
-1
```


### Ví dụ 2:

### Input:


```
7
```



### Output:


```
0
```



### Ví dụ 3:

### Input:


```
32
```


### Output:


```
1
```
