# Unknown

**URL:** https://oj.tica.edu.vn/problem/tica_locha924b1

---

Cho 4 số nguyên a, b, c, d trong đó a ≤ b và c ≤ d (-10^18 ≤ a, b, c, d ≤ 10^18).

Yêu cầu: Tính số lượng số nguyên khác nhau thuộc hai đoạn [a, b] và [c, d].

#Ví dụ:
##Input



```
3 5 7 9
```

##Output



```
6
```

#Ví dụ 2:
##Input



```
4 9 3 5
```

##Output


```
7
```
