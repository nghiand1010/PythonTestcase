# Bài 179: Đoạn con có giá trị nhỏ nhất

## Đề bài

Cho dãy số nguyên:

```text
A = (a1, a2, ..., an)
```

và một số nguyên dương `k ≤ n`.

Với mỗi giá trị `i` (`1 ≤ i ≤ n - k + 1`), hãy xác định giá trị nhỏ nhất của đoạn gồm `k` phần tử liên tiếp:

```text
a[i], a[i + 1], ..., a[i + k - 1]
```

## Đầu vào

- Dòng 1 chứa hai số nguyên dương `n` và `k`.
- Dòng 2 chứa `n` số nguyên dương `a1, a2, ..., an`.

## Ràng buộc

```text
1 ≤ k ≤ n ≤ 10^3
1 ≤ A[i] ≤ 100, i = 1..n
```

## Đầu ra

Ghi ra màn hình `n - k + 1` dòng, dòng thứ `i` ghi giá trị nhỏ nhất trong các phần tử thuộc đoạn:

```text
a[i], a[i + 1], ..., a[i + k - 1]
```

## Ví dụ

### Đầu vào

```text
5 3
2 1 5 3 4
```

### Đầu ra

```text
1
1
3
```
