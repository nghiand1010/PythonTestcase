# Unknown

**URL:** https://oj.tica.edu.vn/problem/contest1_chuoidouble

---

Một palindrome là một chuỗi đọc giống nhau từ trái sang phải và từ phải sang trái. Ví dụ, các chuỗi ~z, aaa, aba,~ và ~abccba~ là các chuỗi đối xứng, còn "~something~" và "~ab~" thì không là palindrome.

Một chuỗi kép được tạo ra bằng cách viết mỗi ký tự của một chuỗi hai lần. Ví dụ, kép của từ "~seeing~" là "~sseeeeiinngg~".

Bạn capybara Bob được mẹ tặng một chuỗi ~S~. Chuỗi ~S~ chỉ chứa các chữ cái thường. Bob muốn làm chuỗi ~S~ thành chuỗi kép, rồi sắp xếp các chữ của ~S~ thành một palidrome sao cho ~S~ được sắp xếp theo thứ tự bảng chữ cái.

Ví dụ ~S~ = "~dcab~", thì chuỗi Bob muốn là "~abcddcba~"

Hãy giúp Bob tạo chuỗi mà bạn ấy muốn.

----------

**Input:**
----------

Nhập vào một chuỗi ~S~ (~1 ≤ len(s) ≤ 255~)
 
**Output:** 
----------

In ra chuỗi Bob muốn

**Ví dụ 1:**
----------

Input:
----------



```
eraslketc
```


Output:
----------



```
aceeklrsttsrlkeeca
```


**Ví dụ 2:**
----------

Input:
----------



```
admstolkppsejiaplkm
```


Output:
----------



```
aadeijkkllmmopppssttsspppommllkkjiedaa
```
