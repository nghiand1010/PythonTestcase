# CHỒNG GẠCH CAO NHẤT

## Mô tả
Nam có **n** viên gạch được đánh số từ 1 đến n. Các viên gạch có **độ cứng** lần lượt là **a1, a2, …, an**.

Một viên gạch có độ cứng **x** nghĩa là Nam có thể **chồng tối đa x viên gạch khác lên trên viên gạch đó**. Nếu chồng nhiều hơn **x** viên thì viên gạch đó sẽ **bị vỡ**.

## Yêu cầu
Hỏi Nam có thể sắp được **chồng gạch cao nhất là bao nhiêu**?

## Dữ liệu đầu vào
Gồm hai dòng:
- Dòng đầu tiên là số nguyên **n** *(1 ≤ n ≤ 10^5)* – số viên gạch.
- Dòng tiếp theo gồm **n** số nguyên **a1, a2, …, an** *(0 ≤ ai ≤ 10^9)*.

## Dữ liệu đầu ra
Gồm **một số nguyên** là kết quả của bài toán.

## Ví dụ

### Ví dụ 1

**Input**
```
3
1 2 1
```

**Output**
```
3
```

### Ví dụ 2

**Input**
```
6
0 0 0 0 0 0
```

**Output**
```
1
```
