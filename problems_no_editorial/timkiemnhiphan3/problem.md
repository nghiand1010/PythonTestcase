# Unknown

**URL:** https://oj.tica.edu.vn/problem/timkiemnhiphan3

---

Cho số nguyên dương 𝑛, hãy tìm số nguyên 𝑚 nhỏ nhất sao cho 𝑚! có không ít hơn 𝑛 chữ số 0 ở cuối.

##**Input**

Gồm:
* Một dòng chứa n

##  **Ràng buộc** 
* n ≤ 10e16

##  **Output** 
In ra kết quả.

## **Ví dụ**
**Input:**

```
3
```

**Output**

```
15
```
